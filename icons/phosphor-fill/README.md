# HUM website icons

[Phosphor Icons](https://phosphoricons.com), fill weight, from `@phosphor-icons/core@2.1.1` — the same library and weight as the HUM app. MIT licensed (see `LICENSE`).

One icon per meaning across the site. The full rules live in the HUM design system's Website section in Claude Design.

| Meaning | File |
| --- | --- |
| Rideshare / app driving | `steering-wheel-fill.svg` |
| Your own clients, client list | `address-book-fill.svg` |
| How it works / the process | `path-fill.svg` |
| Questions, FAQ | `question-fill.svg` |
| Where HUM operates | `map-pin-fill.svg` |
| Covered on a logged ride, Ride Assurance | `shield-check-fill.svg` |
| Insurance policy | `umbrella-fill.svg` |
| Same trusted driver | `handshake-fill.svg` |
| Legality | `scales-fill.svg` |
| Business / commercial | `briefcase-fill.svg` |
| Your rate, pricing, earnings | `currency-circle-dollar-fill.svg` |
| A note or caveat | `info-fill.svg` |
| A benefit in a list | `check-circle-fill.svg` |
| A pain point in a list | `x-circle-fill.svg`, `minus-circle-fill.svg` |
| Expand / collapse | `plus-circle-fill.svg`, `caret-down-fill.svg` |

The SVGs use `fill="currentColor"`: inline them so they take the surrounding text colour (an `<img>` tag can't recolour them).
